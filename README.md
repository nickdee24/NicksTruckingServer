# Nick's Trucking Server

A private, HaulMP-style setup for Euro Truck Simulator 2, built around the official ETS2 Dedicated Server (Convoy).

| Folder | What lives there |
| --- | --- |
| `server/` | Dedicated server config and start/stop scripts |
| `hub/` | Node.js hub service: news, updates, mod pack, live positions, map |
| `launcher/` | Electron launcher: splash, news, server select, Play |
| `mods/` | Mod pack and graphics presets synced to players |
| `docs/` | Notes and setup guides |

Large installs live outside the repo on `D:\TruckingServerData` (SteamCMD and the dedicated server).

All branding and artwork here is original. No HaulMP or SCS logos or assets are included.
